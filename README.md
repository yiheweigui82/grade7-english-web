# 阳光英语 · Sunshine English

一个离线可用的七年级英语教材学习网站，把教材内容整理为可交互页面。

## 使用

直接用浏览器打开：

- `unit1/index.html` — Unit 1 · This is me!
- `unit2/index.html` — Unit 2 · Hobbies

请保持每个 `unit` 文件夹中的 `assets` 目录完整。网站不需要服务器或联网，单词和例句朗读音频已随项目提供。

## 功能

- 小学熟词与单元新词区分显示
- 点击新词查看中文释义、例句、翻译、词根词缀拆解和朗读
- 练习检查、答案提示、作文编辑、进度和单词本本地保存
- 男生／女生配色切换，支持手机和电脑窗口
- 教材原页对照

## 内容说明

内容根据用户提供的教材照片整理。Unit 2 的听力部分未附原始录音，因此页面保留题型并支持导入本地录音。中文释义、构词说明和例句用于辅助学习，不替代教材或教师讲解。

## 发布到 GitHub

将此目录上传到 GitHub 后，可使用 GitHub Pages 发布：在仓库 Settings → Pages 中选择部署分支和根目录。访问对应的 `unit1/index.html` 或 `unit2/index.html` 即可。
