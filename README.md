# 阳光英语 · Sunshine English

一个离线可用的七年级英语教材学习网站，把教材内容整理为可交互页面。

## 使用（在线版，推荐）

点下面链接直接打开，无需安装任何东西：

- 🌐 网站首页（两个单元入口）：https://yiheweigui82.github.io/grade7-english-web/
- 🌐 Unit 1 · This is me!：https://yiheweigui82.github.io/grade7-english-web/unit1/index.html
- 🌐 Unit 2 · Hobbies：https://yiheweigui82.github.io/grade7-english-web/unit2/index.html

## 离线使用

网站不需要服务器或联网，也可下载后本地打开（适合没有网络的环境）：

1. 点仓库页面绿色的 **Code** 按钮 → **Download ZIP**（或直接下载 `unit1.zip` / `unit2.zip` 单个单元包）
2. 解压后双击 `index.html`（或在 `unit1` / `unit2` 文件夹中双击对应的 `index.html`）

> ⚠️ 请保持每个 `unit` 文件夹中的 `assets` 目录完整，不要单独移动里面的文件，否则音频和图片会失效。单词和例句朗读音频已随项目提供。

## 功能

- 小学熟词与单元新词区分显示
- 点击新词查看中文释义、例句、翻译、词根词缀拆解和朗读
- 练习检查、答案提示、作文编辑、进度和单词本本地保存
- 男生／女生配色切换，支持手机和电脑窗口
- 教材原页对照

## 内容说明

内容根据用户提供的教材照片整理。Unit 2 的听力部分未附原始录音，因此页面保留题型并支持导入本地录音。中文释义、构词说明和例句用于辅助学习，不替代教材或教师讲解。
